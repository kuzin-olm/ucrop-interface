# Design Specification: Кабинет организации (Profile / Organization)

**Продукт:** CropOptimize  
**Версия:** MVP 1.0  
**Дата:** 17.08.2026  
**Экран:** Кабинет организации  
**Ответственный дизайн:** Senior UI/UX  

Этот документ является единым источником правды для кабинета организации (профиля).  
Любые изменения, связанные с тарифом, платежами и данными организации, должны опираться на этот файл.

---

## 1. Цель

Кабинет организации позволяет:
- Видеть и редактировать основные данные организации
- Понимать текущий тарифный план (по умолчанию Free)
- Видеть использование лимитов
- Просматривать историю платежей

**Важно:** интерфейс должен быть спокойным, без агрессивного давления «купить тариф».

---

## 2. Точка входа

Кнопка перехода в кабинет находится **в меню пользователя** (правый верхний угол), рядом с пунктом «Выйти».

**Меню пользователя:**
- Профиль / Организация
- Настройки (если есть)
- Выйти

Клик по «Организация» / «Профиль» открывает кабинет.

Стиль табов — как в других справочниках (Материалы и т.п.).

---

## 4. Таб «Основная»

### 4.1. Блок «Информация об организации»

- Название организации
- ИНН (опционально)
- Регион
- Кнопка «Редактировать»

### 4.2. Блок «Текущий тариф»

- Крупный спокойный badge тарифа: **Free** (по умолчанию)
- Короткое нейтральное описание:  
  «Подходит для знакомства с платформой»
- Мягкая строка использования:  
  `2 из 5 планов · 12 полей · 3 сотрудника`
- Кнопка вторичного стиля: **«Смотреть тарифы»**  
  (не «Купить», не «Улучшить сейчас»)

### 4.3. Блок «Что входит в Free»

Список возможностей текущего тарифа с зелёными галочками.  
Без зачёркнутых пунктов и красных ограничений.

Примеры:
- До 5 планов
- До 12 полей
- До 3 сотрудников
- Базовые агрономические инструменты
- Базовая поддержка

---

## 5. Таб «Платежи»

### 5.1. Если платежей ещё не было

Empty state:
- Заголовок: «Пока нет платежей»
- Текст: «При переходе на платный тариф история платежей появится здесь.»
- Без агрессивных CTA

### 5.2. Если платежи есть

Таблица / список:

| Дата | Описание | Сумма | Статус | Документ |
|------|----------|-------|--------|----------|
| ...  | Оплата тарифа Pro | 4 900 ₽ | Оплачен | Скачать |

Статусы: Оплачен / Ожидает / Отменён.

---

## 6. Принципы «не пугать пользователя»

1. Не использовать красные предупреждения и «Upgrade now».
2. Лимиты показывать мягко (X из Y), а не «осталось 0».
3. Кнопка апгрейда — вторичная: «Смотреть тарифы».
4. На Free показывать, **что можно**, а не длинный список запретов.
5. Empty state платежей — спокойный и информативный.

---

## 10. Правила для будущих фич

1. Тариф по умолчанию всегда **Free**.
2. Не добавлять навязчивые баннеры апгрейда в MVP.
3. Страница сравнения тарифов («Смотреть тарифы») может быть отдельным экраном/модалкой.
4. Редактирование организации — через модалку или inline.
5. Платежи только для администратора организации.
