# Design Specification: Экран «Культуры» (Crops)

**Продукт:** CropOptimize  
**Версия:** MVP 1.0  
**Дата:** 14.08.2026  
**Экран:** Культуры организации  
**Ответственный дизайн:** Senior UI/UX  

Этот документ является единым источником правды (Single Source of Truth) для экрана «Культуры».  
Любая новая фича, связанная с культурами, должна опираться на этот файл.

---

## 1. Цель экрана

Экран «Культуры» позволяет агроному и администратору организации:

- Видеть полный каталог культур, которые организация **уже сеет** или **планирует сеять**.
- Быстро понимать ключевые параметры каждой культуры (урожайность, сроки, почва, маржинальность).
- Добавлять новые культуры в каталог организации.
- Использовать культуры как источник данных при создании планов расчёта.

**Jobs-to-be-Done:**
- «Я хочу быстро понять, какие культуры у нас в обороте и насколько они выгодны».
- «Я хочу добавить новую культуру, чтобы использовать её в будущих планах оптимизации».
- «Я хочу видеть историю результатов по культурам».

---

## 2. Позиция в навигации

**Sidebar (левое меню):**
- Dashboard
- Планы расчёта
- Поля
- **Культуры** ← активный пункт
- Settings (внизу)

Активное состояние: тёмно-зелёный фон (`#2E7D32`), белая иконка и текст.

**Иконка в сайдбаре:** колос / растение (lucide: `sprout` или `wheat`).

---

## 3. Структура экрана (Layout)

```
┌─────────────────────────────────────────────────────────────────────┐
│ Top Bar (logo + search + season + notifications + user)             │
├────────────┬────────────────────────────────────────────────────────┤
│            │  Header: «Культуры организации»  +  [+ Добавить культуру] │
│  Sidebar   │                                                        │
│            │  Filters / Tabs:  Все | Зерновые | Масличные | Бобовые   │
│            │                                                        │
│            │  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│            │  │ Crop Card│ │ Crop Card│ │ Crop Card│ │ Crop Card│   │
│            │  └──────────┘ └──────────┘ └──────────┘ └──────────┘   │
│            │  ┌──────────┐ ┌──────────┐ ┌──────────┐                │
│            │  │ Crop Card│ │ Crop Card│ │ Crop Card│                │
│            │  └──────────┘ └──────────┘ └──────────┘                │
```

- **Максимальная ширина контента:** 1440–1600px  
- **Отступы контента:** 32px слева/справа от сайдбара  
- **Сетка карточек:** 3 колонки на ≥1280px, 2 колонки на 1024–1279px, 1 колонка на <1024px  
- **Gap между карточками:** 20–24px

## 4. Элементы интерфейса

### 4.1. Header

- Заголовок: **«Культуры организации»** (24–28px, SemiBold, `#1A2E1A`)
- Справа: Primary Button  
  - Текст: `+ Добавить культуру`  
  - Цвет: `#2E7D32`  
  - Hover: `#1B5E20`  
  - Radius: 10–12px  
  - Иконка: плюс

### 4.2. Фильтры / Табы

Горизонтальные табы (или segmented control):

| Таб          | Поведение                          |
|--------------|------------------------------------|
| Все          | Показывает все культуры            |
| Зерновые     | Пшеница, Ячмень, Кукуруза, Овёс…  |
| Масличные    | Подсолнечник, Рапс, Соя…           |
| Бобовые      | Горох, Соя, Нут…                   |

- Активный таб: зелёный текст + нижняя граница или фон `Primary Light`
- Неактивный: `#5C6B5C`

### 4.3. Карточка культуры (Crop Card)

**Размер:** примерно 320–360px шириной, высота по контенту (минимум ~220px).

**Структура карточки (сверху вниз):**

1. **Шапка карточки**
   - Иконка культуры (слева) + Название (18px SemiBold)
   - Справа: Status Badge

2. **Статус Badge**
   - `Сеем сейчас` → зелёный (`#E8F5E9` фон + `#2E7D32` текст)
   - `Планируем` → жёлтый/оранжевый (`#FFF8E1` + `#F9A825`)
   - `История` → серый (`#F5F5F5` + `#90A4AE`)

3. **Основные параметры** (список с иконками):
   - Урожайность (ср.): `4,2 т/га`
   - Сроки сева: `25.04 – 15.05`
   - Предпочтительная почва: `Чернозём`
   - Маржинальность: `Высокая` / `Средняя` / `Низкая` (цветной текст)

4. **Блок «Результат прошлого сезона»**
   - Мини-линейный график (sparkline)
   - Значение: `4,1 т/га`
   - Цвет линии графика зависит от культуры или тренда

5. **Hover-состояние карточки**
   - Лёгкая тень увеличивается
   - Появляется кнопка «Подробнее» или курсор pointer
   - Клик по всей карточке открывает Drawer / Detail View

**Визуальные токены карточки:**
- Background: `#FFFFFF`
- Border: `1px solid #E0E7E0` (или без border + тень)
- Border-radius: `16px`
- Padding: `20–24px`
- Shadow: `0 4px 12px rgba(0, 0, 0, 0.06)`

### 4.4. Иконки культур

Рекомендуемый набор (можно использовать Lucide / custom SVG):

- Пшеница → wheat
- Кукуруза → corn
- Соя → bean
- Подсолнечник → sunflower
- Ячмень → barley / wheat
- Рапс → flower / leaf
- Горох → circle-dot

Цвет иконок: `#2E7D32` или нейтральный тёмно-зелёный.

## 5. Состояния экрана

### 5.1. Loading
- Skeleton-карточки (3–6 штук) в той же сетке
- Пульсирующий эффект

### 5.2. Empty State
- Центрированная иллюстрация (растение / пустой каталог)
- Заголовок: «Пока нет культур»
- Подзаголовок: «Добавьте первую культуру, чтобы использовать её в планах оптимизации»
- Primary Button: `+ Добавить культуру`

### 5.3. Error State
- Иконка ошибки
- Текст: «Не удалось загрузить культуры»
- Кнопка «Повторить»

### 5.4. Populated (основное)
- Сетка карточек + табы + header

## 7. Данные карточки (Data Model)

Минимальный набор полей, которые должна отдавать API:

```ts
interface Crop {
  id: string;
  name: string;                    // "Пшеница"
  category: "grain" | "oilseed" | "legume" | "other";
  status: "sowing_now" | "planned" | "history";
  averageYield: number;            // т/га
  yieldUnit: "t/ha";
  sowingWindow: {
    start: string;                 // "25.04"
    end: string;                   // "15.05"
  };
  preferredSoil: string;           // "Чернозём"
  marginPotential: "high" | "medium" | "low";
  lastSeasonResult: {
    yield: number;
    trend: number[];               // для sparkline
  };
  icon?: string;                   // ключ иконки
}
```

## 8. Drawer / Detail View (будущее расширение)

При клике на карточку открывается правый Drawer (ширина 420–480px) со следующей информацией:

- Большая иконка + название + статус
- Полные параметры
- История урожайности (график за 3–5 лет)
- Список полей, где эта культура использовалась
- Кнопки: «Редактировать», «Использовать в новом плане»

Этот Drawer должен быть описан в отдельном `design-crop-detail.md` при развитии фичи.

---

## 9. Форма «Добавить культуру» (Modal)

**Триггер:** кнопка `+ Добавить культуру`

**Поля формы:**
- Название культуры (обязательно)
- Категория (select: Зерновые / Масличные / Бобовые / Другое)
- Статус по умолчанию (Планируем)
- Средняя урожайность (number)
- Сроки сева (два date-поля или текстовые)
- Предпочтительная почва (text или select)
- Маржинальность (select)

**Кнопки:** «Отмена» (ghost) + «Добавить» (primary)

После успешного добавления:
- Модалка закрывается
- Новая карточка появляется в сетке
- Toast: «Культура добавлена»

## 11. Accessibility

- Все интерактивные элементы имеют `focus-visible` кольцо зелёного цвета
- Контраст текста ≥ 4.5:1
- Карточки доступны с клавиатуры (Tab + Enter)
- Status Badge имеют текстовое значение (не только цвет)
- Иконки имеют `aria-hidden="true"` + рядом текстовая метка

---

## 12. Правила для будущих фич

1. Любая новая информация о культуре сначала появляется в **Drawer**, а не перегружает карточку.
2. Карточка должна оставаться «сканируемой» за 2–3 секунды.
3. Статус (`Сеем сейчас` / `Планируем` / `История`) — главный визуальный маркер.
4. При добавлении связи «Культура ↔ Поле» или «Культура ↔ План» — обновлять данные на этом экране через invalidation кэша.
5. Не добавлять на карточку больше 5 ключевых параметров.
