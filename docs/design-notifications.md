# Design Specification: Уведомления (Notifications)

**Продукт:** CropOptimize  
**Версия:** MVP 1.0  
**Дата:** 17.08.2026  
**Компонент:** Колокольчик + панель уведомлений  
**Ответственный дизайн:** Senior UI/UX  

Этот документ является единым источником правды для системы уведомлений.  
Любые изменения колокольчика и панели уведомлений должны опираться на этот файл.

---

## 1. Цель

Уведомления сообщают пользователю о важных событиях платформы без визуального шума и давления.

Основные типы событий:
- Завершение / ошибка расчёта плана
- Действия команды (принятие приглашения и т.п.)
- Мягкие системные сообщения (лимиты тарифа)

---

## 2. Колокольчик (Top Bar)

**Расположение:** правая часть топ-бара, рядом с меню пользователя.

**Состояния:**
- Нет непрочитанных → обычная иконка колокольчика
- Есть непрочитанные → **красная точка** на иконке (без цифры)

**Поведение:**
- Клик открывает выпадающую панель
- Повторный клик / клик вне панели — закрывает

---

## 3. Панель уведомлений (Dropdown)

### 3.1. Общий вид
- Белая панель, мягкая тень, скругление 12–16px
- Выравнивание по правому краю относительно колокольчика
- Минималистичный дизайн, без крупных иконок

### 3.2. Шапка
- Слева: **«Уведомления»**
- Справа: текстовая ссылка **«Прочитать все»**

### 3.3. Список уведомлений

Каждая строка:
- Текст слева
- Время справа (приглушённый серый)

**Формат времени:**
`1м` · `5м` · `10м` · `30м` · `1ч` · `вчера` · `давно`

**Приоритет / тип — только через лёгкий фон строки:**
- Успех (расчёт завершён) → очень светлый зелёный фон
- Ошибка / предупреждение → очень светлый тёплый (beige) фон
- Обычное → белый фон

**Непрочитанное:**
- Чуть более плотный/жирный текст
- И/или едва заметный фон
- Без цветных точек и badge

**Запрещено в MVP:**
- Крупные цветные иконки
- Цифровой badge на колокольчике
- Яркие красные/оранжевые акценты внутри списка

### 3.4. Подвал
- Ссылка **«Все уведомления»** (на будущее, можно вести на полную страницу)

---

## 4. Поведение строк

- Клик по уведомлению:
  - Переход к связанному объекту (план, результаты, сотрудники)
  - Помечание как прочитанное
- «Прочитать все» — снимает все непрочитанные

---

## 5. Примеры текстов

| Событие | Текст |
|---------|--------|
| Расчёт завершён | Расчёт «Оптимизация весна 2026» завершён |
| Ошибка расчёта | Ошибка в плане «Кукуруза – Тест» |
| Приглашение принято | Мария Иванова приняла приглашение |
| Обновление плана | План «Озимая пшеница 2026» обновлён |
| Лимит тарифа | Использовано 4 из 5 планов |

Тексты — короткие, без восклицательных знаков и маркетинга.

---

## 6. Data Model

```ts
interface Notification {
  id: string;
  type: "success" | "error" | "info" | "system";
  title: string;
  body?: string;
  createdAt: string;          // ISO
  read: boolean;
  link?: string;              // deep link to plan / results / employees
}
```

**Отображение времени (клиент):**
- < 1 мин → `1м`
- < 1 часа → `5м` / `10м` / `30м`
- < 24 ч → `1ч`
- вчера → `вчера`
- старше → `давно`

---

## 8. Состояния

### Пустой список
- Текст: «Нет уведомлений»
- Без иллюстраций в MVP

### Loading
- Skeleton 3–4 строк

---

## 9. Правила

1. Колокольчик показывает **только красную точку**, никогда цифру.
2. Приоритет выражается фоном строки, а не иконками.
3. Время — короткое и справа.
4. Дизайн максимально спокойный и минималистичный.
5. Непрочитанные отличаются плотностью текста / лёгким фоном, не яркими маркерами.

---

## 10. Связанные экраны

- Планы расчёта (завершение / ошибка)
- Результаты расчёта
- Сотрудники (приглашения)
- Кабинет организации (лимиты тарифа)
