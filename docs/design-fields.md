# Design Specification: Экран «Поля» (Fields)

**Продукт:** CropOptimize  
**Версия:** MVP 1.0  
**Дата:** 15.08.2026  
**Экран:** Поля организации  
**Ответственный дизайн:** Senior UI/UX  

Этот документ является единым источником правды (Single Source of Truth) для экрана «Поля».  
Любая новая фича, связанная с полями, должна опираться на этот файл.  
Документ построен по той же структуре и принципам, что и `design.md` для экрана «Культуры».

---

## 1. Цель экрана

Экран «Поля» позволяет агроному и администратору организации:

- Видеть полный список всех полей организации с ключевыми характеристиками.
- Ориентироваться по интерактивной карте (расположение, площадь, статус).
- Фильтровать поля по почве, предшественнику и площади.
- Добавлять новые поля.
- Открывать детальную информацию о поле в правом Drawer.
- Запускать оптимизацию прямо с выбранного поля.

**Jobs-to-be-Done:**
- «Я хочу быстро увидеть все поля хозяйства и их текущий статус».
- «Я хочу понять, какие поля готовы к планированию посева».
- «Я хочу добавить новое поле и сразу использовать его в планах расчёта».
- «Я хочу кликнуть по полю и увидеть его характеристики и историю».

---

## 2. Позиция в навигации

**Sidebar (левое меню):**
- Dashboard
- Планы расчёта
- **Поля** ← активный пункт
- Культуры
- Settings (внизу)

Активное состояние: тёмно-зелёный фон (`#2E7D32`), белая иконка и текст.

**Иконка в сайдбаре:** карта / локация (lucide: `map-pin` или `map`).

---

## 3. Структура экрана (Layout)

```
┌─────────────────────────────────────────────────────────────────────┐
│ Top Bar (logo + search + season + notifications + user)             │
├────────────┬────────────────────────────────────────────────────────┤
│            │  Header: «Поля организации»  +  [+ Добавить поле]       │
│  Sidebar   │  Подзаголовок: «24 поля • 4 782,6 га»                  │
│            │                                                        │
│            │  Filters: Почва | Предшествующая культура | Площадь    │
│            │                                                        │
│            │  ┌─────────────────────────────────────────────────┐   │
│            │  │           Интерактивная карта полей             │   │
│            │  │     (цветные полигоны + подписи + легенда)      │   │
│            │  └─────────────────────────────────────────────────┘   │
│            │                                                        │
│            │  Таблица полей                                          │
│            │                                                        │
│            │  (Empty / Loading / Error — при необходимости)         │
└────────────┴────────────────────────────────────────────────────────┘
```

- **Максимальная ширина контента:** 1440–1600px  
- **Отступы контента:** 32px слева/справа от сайдбара  
- **Карта:** верхняя основная зона (высота ~380–450px)  
- **Таблица:** под картой  
- **Gap** между блоками: 24px

## 4. Элементы интерфейса

### 4.1. Header

- Заголовок: **«Поля организации»** (24–28px, SemiBold, `#1A2E1A`)
- Подзаголовок: `24 поля • 4 782,6 га` (14px, `#5C6B5C`)
- Справа: Primary Button  
  - Текст: `+ Добавить поле`  
  - Цвет: `#2E7D32`  
  - Hover: `#1B5E20`  
  - Radius: 10–12px  
  - Иконка: плюс

### 4.2. Фильтры

Горизонтальный ряд фильтров (select / dropdown):

| Фильтр                    | Варианты                                            |
|---------------------------|-----------------------------------------------------|
| Почва                     | Все типы, Чернозём, Каштановая, Серая лесная…       |
| Предшествующая культура   | Все культуры + список из каталога организации       |
| Площадь                   | Все диапазоны, < 50 га, 50–100 га, > 100 га         |

- Справа: текстовая ссылка «Сбросить фильтры»
- Активный фильтр подсвечивается зелёным

### 4.3. Интерактивная карта

- Стиль: спутниковый / hybrid
- Цветные полигоны полей с подписями (`Поле 3  72,4 ha`)
- Цвета полигонов соответствуют статусу или типу угодий
- Легенда справа внизу карты
- Контролы zoom и fit bounds — слева
- Клик по полигону → подсветка + открытие **правого Drawer** с деталями поля
- Hover → tooltip с названием и площадью

### 4.4. Таблица полей

Колонки:

| Колонка                     | Описание                                      |
|-----------------------------|-----------------------------------------------|
| Поле                        | Цветная точка статуса + название              |
| Площадь (га)                | Число с одним знаком после запятой            |
| Тип почвы                   | Текст                                         |
| Предшествующая культура     | Название культуры                             |
| Статус                      | Badge                                         |
| Показатели (pH / NPK)       | `pH 6,4  N 18 P 24 K 198`                     |
| Действия                    | Меню `⋯` (Открыть, Редактировать, Оптимизировать) |

**Статус Badge:**
- `Активно` → зелёный (`#E8F5E9` + `#2E7D32`)
- `Планируется` → синий/голубой
- `В обработке` → жёлтый/оранжевый (`#FFF8E1` + `#F9A825`)
- `Не активно` → серый (`#F5F5F5` + `#90A4AE`)

**Визуальные токены таблицы:**
- Background: `#FFFFFF`
- Hover строки: `#F1F8F1`
- Border: `#E0E7E0`
- Radius обёртки: `16px`
- Padding ячеек: `12–16px`

## 5. Состояния экрана

### 5.1. Loading
- Skeleton карты + skeleton-строки таблицы (6–8 шт.)

### 5.2. Empty State
- Иллюстрация (карта / пустое поле)
- Заголовок: «Пока нет полей»
- Подзаголовок: «Добавьте первое поле, чтобы начать планирование посевов»
- Primary Button: `+ Добавить поле`

### 5.3. Error State
- Текст: «Не удалось загрузить поля»
- Кнопка «Повторить»

### 5.4. Populated
- Карта + таблица + фильтры + header

### 5.5. Нет результатов фильтрации
- Текст: «По выбранным фильтрам ничего не найдено»
- Кнопка «Сбросить фильтры»

## 7. Данные поля (Data Model)

```ts
interface Field {
  id: string;
  name: string;                    // "Поле 3" или "Участок Север-2"
  area: number;                    // 72.4
  areaUnit: "ha";
  soilType: string;                // "Чернозём типичный"
  previousCrop: string | null;     // "Пшеница озимая"
  status: "active" | "planned" | "in_progress" | "inactive";
  indicators: {
    ph: number;
    n: number;
    p: number;
    k: number;
  };
  geometry: GeoJSON.Polygon;       // для карты
  color?: string;
  history?: {                      // для Drawer
    year: number;
    crop: string;
    yield: number;
  }[];
}
```

## 8. Правый Drawer — Детали поля (аналог Crop Detail)

При клике на поле (карта или таблица) открывается **правый Drawer** шириной **420–480px**.

### Структура Drawer

1. **Шапка**
   - Название поля (крупно)
   - Площадь + Status Badge
   - Кнопка закрытия (X)

2. **Основные параметры**
   - Тип почвы
   - Предшествующая культура
   - pH / NPK (с небольшими индикаторами)

3. **Мини-карта**
   - Выделенный контур текущего поля

4. **История посевов** (последние 3–5 лет)
   - Год | Культура | Урожайность
   - Можно в виде простого списка или мини-графика

5. **Действия внизу Drawer**
   - Primary: «Оптимизировать» (создаёт новый план с этим полем)
   - Secondary: «Редактировать»
   - Ghost: «Добавить в существующий план»

**Поведение:**
- Drawer наезжает справа поверх контента
- Фон основного экрана слегка затемняется (overlay)
- Закрытие: по X, по клику на overlay или Escape
- Анимация: slide-in справа

Этот Drawer полностью аналогичен по паттерну Drawer’у культуры (раздел 8 в design.md «Культуры»).

## 9. Форма «Добавить поле» (Modal)

**Триггер:** кнопка `+ Добавить поле`

**Поля формы:**

| Поле                        | Тип                  | Обязательность | Примечание                     |
|-----------------------------|----------------------|----------------|--------------------------------|
| Название поля               | text                 | да             |                                |
| Площадь (га)                | number               | да             |                                |
| Тип почвы                   | select / text        | да             |                                |
| Предшествующая культура     | select               | нет            | из списка культур организации  |
| Статус                      | select               | да             | по умолчанию «Активно»         |
| pH                          | number               | нет            |                                |
| N / P / K                   | number               | нет            | мг/кг                          |

**Дополнительно (MVP-заметка):**
- «Контур поля можно будет загрузить или нарисовать позже»

**Кнопки:**
- «Отмена» (ghost)
- «Добавить поле» (primary)

**После успешного добавления:**
- Модалка закрывается
- Новое поле появляется на карте и в таблице
- Toast: «Поле добавлено»

## 11. Accessibility

- Все интерактивные элементы имеют `focus-visible` кольцо зелёного цвета
- Контраст текста ≥ 4.5:1
- Таблица, карта и Drawer доступны с клавиатуры
- Status Badge имеют текстовое значение (не только цвет)
- Полигоны на карте имеют `aria-label` с названием и площадью
- Drawer можно закрыть клавишей Escape

---

## 12. Правила для будущих фич

1. Карта — главный визуальный элемент экрана. Не перегружать её лишними слоями в MVP.
2. Любая новая информация о поле сначала появляется в **правом Drawer**, а не в таблице.
3. Статус поля — главный визуальный маркер (и на карте, и в таблице).
4. При создании плана расчёта должна быть возможность выбрать несколько полей.
5. Не добавлять в таблицу больше 7 колонок.
6. Геометрия поля (контур) хранится и используется для карты и будущих расчётов.
7. Паттерн Drawer’а должен оставаться идентичным Drawer’у культуры.

---

## 13. Связанные экраны

- **Dashboard** — количество активных полей и карта-превью
- **Планы расчёта** — используют список полей при создании плана
- **Культуры** — показывают предшествующую культуру на полях
- **Оптимизатор / Создание плана** — можно запустить с выбранного поля
