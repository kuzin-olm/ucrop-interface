# Design Specification: Экран «Материалы» + цена реализации в «Культуры»

**Продукт:** CropOptimize  
**Версия:** MVP 1.0  
**Дата:** 16.08.2026  
**Экраны:** Материалы + дополнение к Культурам  
**Ответственный дизайн:** Senior UI/UX  

Этот документ является единым источником правды для:
1. Таба **«Материалы»**
2. Добавления **цены реализации** в таб **«Культуры»**

---

## 1. Цель

Для корректной оптимизации маржинальной прибыли системе нужны:

- **Цена реализации культуры** → хранится в справочнике «Культуры»
- **Материалы и их цены** → отдельный справочник «Материалы» (семена, удобрения, СЗР, ГСМ)

Без этих данных «максимизация маржинальной прибыли» невозможна.

---

## 2. Таб «Материалы»

### 2.1. Позиция в навигации

**Sidebar:**
- Dashboard
- Планы расчёта
- Поля
- Культуры
- **Материалы** ← новый пункт
- Сотрудники
- Settings

**Иконка:** package / box (lucide: `package` или `boxes`)

### 2.2. Структура экрана

- Header: «Материалы» + кнопка `+ Добавить материал`
- Фильтры по категориям: **Все | Семена | Удобрения | СЗР | ГСМ**
- Поиск по названию
- Таблица материалов

### 2.3. Колонки таблицы

| Колонка            | Описание                                      |
|--------------------|-----------------------------------------------|
| Название материала | Название + опционально подпись (марка/сорт)   |
| Категория          | Badge: Семена / Удобрения / СЗР / ГСМ         |
| Ед. изм.           | кг, л, т, п.е. и т.д.                         |
| Цена за ед. (₽)    | Цена за одну единицу измерения                |
| Статус             | Активен / Не используется                     |
| Действия           | Редактировать                                 |

### 2.4. Категории материалов (строго)

1. **Семена**
2. **Удобрения**
3. **СЗР** (средства защиты растений)
4. **ГСМ** (горюче-смазочные материалы)

Категория «Прочее» **не используется**.

### 2.5. Форма добавления / редактирования материала

Поля:
- Название *
- Категория * (Семена / Удобрения / СЗР / ГСМ)
- Единица измерения * (кг / л / т / п.е. / шт)
- Цена за единицу (₽) *
- Статус (Активен / Не используется)
- Примечание (необязательно)

### 2.6. Data Model — Материал

```ts
interface Material {
  id: string;
  name: string;
  category: "seeds" | "fertilizer" | "ppp" | "fuel";  // ppp = plant protection products
  unit: "kg" | "l" | "t" | "se" | "pcs";               // se = посевная единица
  pricePerUnit: number;                               // ₽
  status: "active" | "inactive";
  note?: string;
}
```

## 3. Дополнение к табу «Культуры» — Цена реализации

### 3.1. Зачем

Цена реализации культуры:
- Необходима для расчёта выручки и маржи
- Меняется от сезона к сезону
- Логично хранится вместе с культурой

### 3.2. Где отображается

1. **На карточке культуры** — новое поле «Цена реализации»
2. **В форме создания / редактирования культуры** — обязательное или рекомендуемое поле
3. **В правом Drawer** деталей культуры

### 3.3. Поле

- Название: **Ожидаемая цена реализации**
- Единица: ₽/т (или ₽/ц — зафиксировать одну)
- Тип: число
- Можно оставить пустым, но для участия в оптимизации маржи желательно заполнять

### 3.4. Обновление Data Model культуры

```ts
interface Crop {
  // ... существующие поля
  expectedSellPrice?: number;     // ₽/т
  sellPriceUnit?: "t" | "c";      // тонна или центнер
}
```

---

## 4. Как это используется в оптимизации

При создании плана (Шаг 3 — культуры + ограничения):

- Система берёт **цену реализации** из справочника культур
- Берёт **цены материалов** из справочника материалов
- (В будущем) нормы внесения материалов на культуру → считает затраты на 1 га
- Маржа = (урожайность × цена реализации) – затраты на материалы (и другие переменные)

В MVP достаточно:
- Цены реализации культуры
- Цены материалов (даже без детальных норм пока можно использовать агрегированные затраты)

## 7. Правила

1. Категорий материалов строго четыре: Семена, Удобрения, СЗР, ГСМ.
2. Цена реализации живёт в «Культуры», а не в «Материалы».
3. «Не используется» — мягкое отключение материала (аналогично статусу сотрудников).
4. В MVP нормы внесения материалов на культуры можно не делать — достаточно справочника цен.
5. Все цены в рублях.
